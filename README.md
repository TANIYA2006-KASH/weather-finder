# Weather Finder
Search any city (or use your location) for current weather and a 5-day forecast. Features °C/°F toggle, recent searches, weather-based themes, loading and error states.

**Tech:** HTML5, CSS3, vanilla JavaScript, [Open-Meteo API](https://open-meteo.com/) (free, no API key)
**Run:** open `index.html` in a browser with internet access.
